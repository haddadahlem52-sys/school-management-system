# Gestion d'école primaire (démo SaaS)

Projet front-end : HTML + CSS + JavaScript, sans installation.

## Ouvrir dans VS Code
1. VS Code > Fichier > Ouvrir le dossier... > choisir `ecole-primaire`.
2. Installer l'extension **Live Server**, puis clic droit sur `index.html` > *Open with Live Server*.
   (Ou simplement double-cliquer sur `index.html` pour l'ouvrir dans le navigateur.)

## Fichiers
- `index.html` : structure de la page
- `style.css`  : thème enfants (couleurs, boutons, tableaux)
- `app.js`     : toute la logique (données, rôles, contrôle de saisie, SaaS)

## Comptes de démonstration
- Plateforme SaaS : `superadmin` / `super123`
- Administrateur de l'école de démonstration : `admin` / `admin123`

Les données sont enregistrées dans le navigateur (localStorage). Pour repartir de zéro :
F12 > Application > Stockage local > effacer.
